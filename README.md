# דף נחיתה – אוזון קליניקס

## העלאה ל-GitHub Pages
1. יוצרים ריפו חדש ב-GitHub (למשל `ozon-landing`).
2. מעלים את כל הקבצים מהתיקייה הזו (`index.html`, `.nojekyll`) לשורש הריפו.
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root` → Save.
4. אחרי כדקה הדף יהיה זמין בכתובת:
   `https://<שם-משתמש>.github.io/ozon-landing/`

## הערות
- הכול בקובץ אחד (`index.html`) כולל לוגו, פונטים וסקריפטים.
- שלוש תמונות (ד״ר עטיאס ופוסטרים לסרטונים) נטענות ישירות מהשרת של ozon-clinics.com, ולכן דורשות חיבור לאינטרנט.
- דומיין מותאם: מוסיפים קובץ `CNAME` עם שם הדומיין, ומגדירים רשומת DNS אצל ספק הדומיין.
