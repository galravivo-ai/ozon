# דף נחיתה – מרפאות אוזון (גרסה 4)

## העלאה ל-GitHub Pages
1. יוצרים ריפו חדש ב-GitHub (למשל `ozon-landing`), או מעדכנים ריפו קיים.
2. מעלים את כל הקבצים מהתיקייה הזו (`index.html`, `.nojekyll`) לשורש הריפו, ומחליפים את הקיימים.
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root` → Save.
4. אחרי כדקה הדף יהיה זמין בכתובת:
   `https://<שם-משתמש>.github.io/ozon-landing/`

## הטמעה באתר קיים / וורדפרס
- `index.html` הוא קובץ עצמאי אחד (לוגו, פונטים וסקריפטים בפנים). אפשר להעלות אותו לכל שרת או לתת לו נתיב כמו `/lp/`.

## הערות
- שלוש תמונות (ד״ר עטיאס ופוסטרים לעדויות) נטענות מהשרת של ozon-clinics.com.
- הטפסים כרגע מציגים הודעת תודה בלבד ולא שולחים לידים. צריך לחבר אותם למערכת הלידים / CRM לפני העלייה לאוויר.
- דומיין מותאם: מוסיפים קובץ `CNAME` עם שם הדומיין, ומגדירים רשומת DNS אצל ספק הדומיין.
